# AI Camera Pro — AICamera3rd

A fresh Android camera project targeting OnePlus 8 (Android 13 / Snapdragon 865). The first milestone focuses on a reliable CameraX camera, vivid daylight color processing, gallery import and save. Neural enhancement is kept as a separately verifiable milestone; no unintegrated model is advertised as AI.

## Build
Open with Android Studio or run `./gradlew assembleDebug`.

## Current status
Initial source scaffold. AI neural model integration and device testing are not yet complete.
